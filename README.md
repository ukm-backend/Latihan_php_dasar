# Latihan PHP Dasar

Kumpulan latihan pemrograman PHP untuk pemula, berisi contoh dan soal-soal yang dikelompokkan per topik.

## Daftar Materi

| File | Topik |
|------|-------|
| `Latihan Logika if Satu Syarat` | Percabangan `if` dengan satu kondisi |
| `Percabangan dua kondisi dan lebih dari dua kondisi` | Percabangan `if-else` dan `if-elseif-else` |
| `Soal-Latihan-While.md` | Latihan perulangan `while` (30 soal, dari level mudah sampai sulit) |

## Cara Penggunaan

1. Baca materi dan contoh pada file topik yang dipelajari.
2. Tuliskan kode PHP untuk menyelesaikan setiap soal.
3. Jalankan kode dengan PHP CLI:

```bash
php nama_file.php
```

## Materi

- **Percabangan (`if`, `else`, `elseif`)**: memahami logika kondisi TRUE/FALSE dan pemilihan alur program.
- **Perulangan `while`**: memahami cara kerja iterasi, mengubah nilai variabel di dalam loop, mencegah infinite loop, serta menerapkannya pada soal-soal seperti faktorial, bilangan prima, dan deret Fibonacci.

> Latihan `while` membatasi penggunaan `for`, `foreach`, `break`, `continue`, dan array agar fokus pada logika dasar perulangan.
